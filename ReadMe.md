## Цифровая экосистема

Мобильное приложение (iOS и Android) + веб-панель для директора, бухгалтера и кассира.
Проект автоматизирует работу сети автомоек: запись клиентов, управление боксами, оплату, акции и аналитику загрузки.

---

## 📱 Приложение для клиентов

### Основные функции

* **Онлайн-запись** на мойку

  * Выбор города, бокса и услуги
  * Отображение доступных временных слотов
  * Возможность предзаписи
* **Выбор и оплата услуг**

  * Онлайн-оплата через приложение
  * Возможность оплаты наличными на месте
* **Программа лояльности**

  * Акция **«Чистый четверг»**
  * Система скидок и персональных предложений
* **Личный кабинет клиента**

  * История посещений
  * Состояние бонусов, рейтинг
  * Управление записями и отмена до момента заезда в бокс
* **Уведомления**

  * Напоминания о записи
  * Уведомления о готовности автомобиля
  * Информация о действующих акциях

## 👥 Пользователи системы

| Роль          | Возможности                                                              |
| ------------- | ------------------------------------------------------------------------ |
| **Клиент**    | Запись, оплата, отмена, рейтинг, история                                 |
| **Кассир**    | Просмотр и проведение оплат, выдача чеков, отметка о приёме наличных     |
| **Оператор**  | Работа с заказами по телефону, управление предзаписями                   |
| **Бухгалтер** | Отчётность по оплатам, интеграция с 1С                                   |
| **Директор**  | Аналитика, загрузка боксов, отчёты, управление скидками и пользователями |

---

## 💼 Веб-приложение (Панель управления)

Доступно для директора, бухгалтера и кассира.

### Функциональность

* **Мониторинг загрузки боксов** (по времени, локации, количеству записей)
* **Отчётность и аналитика**

  * По количеству машин
  * По оплатам (наличные и безналичные)
  * Прогнозирование загруженности
* **Управление клиентами**

  * Добавление в **черный список**
  * Назначение **ВИП-статуса**
  * Контракты на льготные тарифы (например, для таксистов)
* **Интеграция с 1С**

  * Передача данных по оплатам и клиентам
  * Автоматическая синхронизация чеков
* **Отмена услуг**

  * Возможна до момента заезда автомобиля в бокс

---

## 🧾 Оплата и чеки

* **Онлайн-оплата** — через мобильное приложение
* **Наличная оплата** — фиксируется кассиром вручную
* **Выдача чека** — автоматическая генерация электронного чека и синхронизация с 1С
* **Отмена услуги** — возможна, пока автомобиль не заехал в бокс

## 🧠 Дополнительные возможности

* Система **рейтинга клиентов** (скорость оплаты, частота визитов)
* **Прогноз загрузки** на основе статистики по часам и дням
* **Контракты с партнёрами** — тарифные скидки для корпоративных клиентов

## 🔐 Регистрация и авторизация
