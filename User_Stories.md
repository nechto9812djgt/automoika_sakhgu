## 📘 Формат User Story

Классическая форма:

> **Как [роль], я хочу [цель], чтобы [ценность/результат].**

---

## 🚗 CleanWay — User Stories

### 🧍 Клиент

| № | User Story                                                                                                                          | Критерии приёмки                                                             |
| - | ----------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------- |
| 1 | Как **клиент**, я хочу **зарегистрироваться по номеру телефона**, чтобы **войти без пароля и быстро начать пользоваться сервисом**. | - Код подтверждения приходит по SMS<br>- После ввода кода создаётся профиль  |
| 2 | Как **клиент**, я хочу **увидеть доступные боксы и свободные слоты**, чтобы **записаться на мойку в удобное время**.                | - Список боксов отображает время и занятость<br>- Можно выбрать город и бокс |
| 3 | Как **клиент**, я хочу **выбрать услугу и оплатить онлайн**, чтобы **не тратить время на оплату на месте**.                         | - Доступны способы оплаты<br>- После оплаты отображается чек                 |
| 4 | Как **клиент**, я хочу **отменить запись до заезда в бокс**, чтобы **не потерять деньги при изменении планов**.                     | - Кнопка отмены активна до статуса “в работе”                                |
| 5 | Как **клиент**, я хочу **получать уведомления**, чтобы **знать, когда мой автомобиль готов**.                                       | - При смене статуса приходит push/SMS                                        |
| 6 | Как **клиент**, я хочу **участвовать в акциях (например, “Чистый четверг”)**, чтобы **получать скидки и бонусы**.                   | - Приложение отображает активные акции                                       |
| 7 | Как **клиент**, я хочу **видеть историю посещений и чеков**, чтобы **контролировать расходы**.                                      | - В личном кабинете доступен список прошлых визитов                          |
| 8 | Как **клиент**, я хочу **иметь рейтинг**, чтобы **получать персональные предложения и привилегии**.                                 | - Баллы начисляются автоматически                                            |

### 💰 Кассир

| №  | User Story                                                                                                 | Критерии приёмки                                                    |
| -- | ---------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------- |
| 9  | Как **кассир**, я хочу **видеть список всех активных записей**, чтобы **подготовиться к приёму клиентов**. | - Таблица с записями за день<br>- Возможность фильтрации по времени |
| 10 | Как **кассир**, я хочу **пометить оплату наличными**, чтобы **учёт был точным и виден бухгалтеру**.        | - Оплата фиксируется и отображается в отчётах                       |
| 11 | Как **кассир**, я хочу **распечатать или отправить чек клиенту**, чтобы **подтвердить оплату**.            | - Есть кнопка “Выдать чек”                                          |
| 12 | Как **кассир**, я хочу **отменить заказ до заезда**, чтобы **освободить бокс**.                            | - Кнопка “Отмена” доступна до статуса “в работе”                    |

### ☎️ Оператор

| №  | User Story                                                                                                | Критерии приёмки                               |
| -- | --------------------------------------------------------------------------------------------------------- | ---------------------------------------------- |
| 13 | Как **оператор**, я хочу **создавать запись по телефону**, чтобы **обслуживать клиентов без приложения**. | - Можно выбрать клиента, время и услугу        |
| 14 | Как **оператор**, я хочу **редактировать записи**, чтобы **исправить ошибки в расписании**.               | - Изменение не влияет на другие брони          |
| 15 | Как **оператор**, я хочу **работать с чёрным и VIP-списками**, чтобы **управлять приоритетом клиентов**.  | - Можно добавить или удалить клиента из списка |

### 📊 Бухгалтер

| №  | User Story                                                                                               | Критерии приёмки                                                 |
| -- | -------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------- |
| 16 | Как **бухгалтер**, я хочу **видеть отчёты по оплатам**, чтобы **сверять кассу и онлайн-платежи**.        | - Отчёт по дням, городам и способам оплаты                       |
| 17 | Как **бухгалтер**, я хочу **экспортировать данные в 1С**, чтобы **автоматизировать бухгалтерский учёт**. | - Отчёт в формате CSV/XML<br>- Автоматическая синхронизация с 1С |
| 18 | Как **бухгалтер**, я хочу **контролировать корректность чеков**, чтобы **избежать налоговых ошибок**.    | - Отчёт о несоответствиях                                        |

### 🧑‍💼 Директор

| -- | ------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------- |

## 🧩 Замечания

* Все роли используют **единое API**.
* Мобильное приложение — для клиентов.
* Веб-панель — для директора, кассира, оператора, бухгалтера.
* Интеграция с 1С — через REST API с обменом XML/JSON.
